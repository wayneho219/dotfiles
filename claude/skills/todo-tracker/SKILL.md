# Todo Tracker

用一份純文字 markdown checklist 追蹤使用者的個人待辦事項。

## 檔案位置

預設用 `~/.claude/TODO.md`（跨專案共用）。若目前專案目錄下已經有 `TODO.md`，優先讀寫那一份，不要重複建立全域的。檔案不存在就建立，內容從 `# Todo\n` 開始。

## 格式

```markdown
# Todo

- [ ] 待辦內容 (2026-07-20)
- [x] 已完成的事 (2026-07-18 → 2026-07-19)
```

- `- [ ]` 未完成，括號是新增日期
- `- [x]` 已完成，括號是「新增日 → 完成日」

## 操作

### 新增待辦
使用者說「加一個待辦：XXX」之類的話：
1. 讀取 TODO.md（不存在就建立）
2. 在清單最後加一行 `- [ ] XXX (今天日期)`
3. 回報新增成功，附上目前未完成待辦數量

### 列出待辦
使用者問「待辦事項」「目前有什麼待辦」：
1. 讀取 TODO.md
2. 只列出未完成（`- [ ]`）項目，依清單順序編號顯示
3. 清單是空的就直接說「目前沒有待辦事項」，不用秀空表格

### 標記完成
使用者說「標記完成」「XXX 做完了」「完成第 N 項」：
1. 用描述或編號（對照「列出待辦」時的順序）找到對應項目
2. 把 `- [ ]` 改成 `- [x]`，日期改成 `新增日 → 今天日期`
3. 比對不到就先列出目前待辦，請使用者確認是哪一項

### 刪除待辦
使用者說「刪掉這個待辦」「不用做了」「取消這項」：
1. 找到對應項目，整行移除
2. 回報已刪除

### 清空已完成
使用者說「清空已完成」「整理一下待辦」：
1. 移除所有 `- [x]` 開頭的行
2. 回報移除了幾筆

## 注意事項

- 已完成項目預設保留在檔案裡當紀錄，不要主動刪除
- 日期一律用 `YYYY-MM-DD`，取當下實際日期，不要用範例裡的日期
- 找不到對應項目時，寧可先列清單請使用者確認，不要用猜的
