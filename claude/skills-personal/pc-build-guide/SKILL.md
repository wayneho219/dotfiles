# 組電腦選購指南

這份 skill 的目的：在使用者組裝或升級電腦時，先過一輪已知的相容性陷阱與經驗法則，避免漏檢查而買錯零件；同時提醒現在的市場行情、型號、優惠會過時，最終價格與新品資訊要請使用者自行核對當下的論壇/比價網站。

## 使用方式

收到規格單或零件清單時，逐項對照下面「相容性檢查清單」，明確指出：
- ✅ 沒問題的部分
- ⚠️ 需要使用者自己再確認的部分（例如：確切的價格、新型號是否已上市、特定通路庫存）
- ❌ 明確的相容性錯誤或已知地雷

不確定的資訊（尤其是型號、價格、上市時間）**不要編造**。目前記憶體、SSD、顯卡都在劇烈漲價（例：DDR5 32GB 一度逼近 1.5 萬台幣），舊經驗法則的價格/預算比例已經不可靠，**只要牽涉到具體價格、現在買不買得到、特定型號的相容性細節（QVL、扣具支援清單、機殼支援尺寸等），一律主動用 web search 查當下的最新資料**，不要單靠這份 skill 裡的靜態知識或記憶回答。查完再告訴使用者，並提醒他自己也去論壇/比價網站再核對一次。這份 skill 提供的是判斷邏輯與檢查項目清單，實際數據要即時查證。

## 台灣 DIY 零件現價查詢（原價屋估價單）

需要台灣 DIY 零件的**當下現金價**時，先跑這支腳本，它會抓原價屋 `evaluate.php`（全站報價都在這一頁）並解析出品項與價格：

```
scripts/coolpc_price.py 9700X 代理盒裝          # 多關鍵字 = 全部命中 (AND)
scripts/coolpc_price.py 990 PRO 2TB --max 20000 # 加價格上下限 --max / --min
scripts/coolpc_price.py --selftest              # 解析器自我測試（不連網）
```

輸出每列為 `[分類] 名稱/規格  $價格`，依價格排序；頁首會標出估價單的更新時間。

適用範圍與限制：
- **只涵蓋原價屋有賣的品項**（CPU、主機板、記憶體、SSD、顯卡、電源、機殼、散熱器、部分筆電/準系統）。查不到不代表沒這東西，只代表原價屋沒上架或關鍵字沒對到，換關鍵字再試。
- 這是**單一通路**報價，只能當行情參考點，不是最低價。
- 價格每個工作日變動，腳本抓到的資料同一天內會快取（`--fresh` 可強制重抓）。

### 跨通路比價

想同時看原價屋 + PChome 24h + 欣亞，用 `scripts/price_compare.py`（同樣關鍵字 AND、`--min/--max`，另有 `--exclude` 濾掉搭售組合包）：

```
scripts/price_compare.py 9700X --exclude 主機板 --exclude 組合
scripts/price_compare.py 990 PRO --max 20000
```

- **蝦皮沒有納入**：API 擋反爬（403），且賣場賣家眾多、水貨/整新品/代購混雜，單一「蝦皮價」參考價值低、維護成本高。要看蝦皮請自己開連結。
- 三家商品命名不一致（`2TB` vs `2T`、含不含「代理盒裝」、PChome 常是「主機板+CPU 組合包」），關鍵字用最短可辨識字串就好，再用 `--exclude` 清雜訊、人工看清單。
- 筆電、品牌機這類原價屋/欣亞沒有的，仍用 web search 查 momo/BigGo 等。
- 一樣是通路報價，重要採購仍要提醒使用者自己到各站、PTT 電蝦版再核對。

## 相容性檢查清單

### CPU / 主機板
- CPU 腳位（socket）要跟主機板腳位完全一致（例如 AMD AM5、Intel LGA1700 / LGA1851 各不相容，不能混用）。
- **BIOS 版本地雷**：主機板即使腳位相同，也可能因為出廠時 BIOS 太舊而認不出新一代 CPU，導致開不了機。如果是舊主機板 + 新 CPU 的組合，要確認：
  - 主機板是否支援「BIOS FlashBack」（免裝 CPU/記憶體就能更新 BIOS）
  - 或商家/店家是否能代刷 BIOS
- 主機板晶片組等級（如入門 B 系列 vs 高階 X/Z 系列）會影響超頻能力、PCIe 通道數、M.2 插槽數量，預算吃緊的中階 CPU 通常不需要買到旗艦晶片組。
- **主機板有沒有內建 WiFi/藍牙**要主動提醒使用者確認。很多人覺得桌機用網路線、用不到 WiFi，就選非 WiFi 版本省一點錢，但同型號 WiFi 版跟非 WiFi 版通常只差一點價差，而藍牙功能是跟著 WiFi 模組一起有的——之後想接藍牙耳機、藍牙搖桿、藍牙鍵鼠這類周邊時，非 WiFi 版本就完全沒有藍牙可用，只能額外買 USB 藍牙/WiFi 擴充卡才能補回來，反而更麻煩。看到規格單上主機板是非 WiFi 版本時，要主動提醒這個取捨，不要預設使用者一定不需要。

**CPU 品牌傾向**：一般使用者（非重度多工/專業渲染需求）預設推薦 AMD，優於 Intel。理由：一般人用不到 Intel 高階型號的核心數量，而核心數越多代表發熱量越高，需要花更多預算在散熱上才壓得住，對一般使用情境來說是不划算的取捨。只有真的有大量多工/多執行緒工作負載（例如大量平行運算、專業渲染、跑很多虛擬機）的使用者，才值得考慮 Intel 高核心數型號。這是經驗判斷，不是絕對規則，遇到明確的重度多工需求時要照需求調整，不要死套。

### 記憶體
- 一定要查主機板官網的 **QVL（Qualified Vendor List，官方驗證相容清單）**，尤其是想跑高頻（如 AMD EXPO / Intel XMP 超過原生頻率）的記憶體，尤其 AMD 平台對記憶體相容性比較挑（Infinity Fabric 時脈連動問題），不在 QVL 上的高頻條有機率開機不穩或跑不到標示頻率。
- 雙通道要買同套裝（同品牌同型號同批），混插不同條容易出問題或無法達到雙通道效能。

### 電源供應器（PSU）
- 瓦數：抓顯卡官方建議的系統瓦數，再抓一點餘裕（不要卡在剛好邊緣），尤其顯卡有瞬間功耗尖峰（transient spike）的問題，太剛好的瓦數容易觸發保護機制跳機。
- 認證等級：至少 80+ 銅牌，建議 80+ 金牌（轉換效率與品質门檻較高）。
- **不要買雜牌/無認證 PSU**，這是電源相關問題最大的地雷來源，壞掉可能連帶燒其他零件。
- 新一代高階顯卡多用 12VHPWR / 12V-2x6 接頭，要確認 PSU 原生支援還是要用轉接頭（轉接頭本身也是潛在故障點，能原生盡量原生）。
- 模組化（全模組/半模組）方便理線但非必要，看預算。
- **機殼尺寸 → PSU 尺寸判斷法則**：如果是緊湊型機殼（如小尺寸 M-ATX、ITX），只要規格表上寫「相容 SFX / SFX-L 電源」，就一律推薦買 SFX 規格的 PSU，不要用標準 ATX 尺寸的 PSU。廠商會特別做出 SFX 相容設計，代表這個機殼塞標準尺寸 PSU 會非常勉強、線材空間不夠，硬塞會讓走線凌亂、影響機殼內部散熱氣流。

### 機殼與散熱
- 顯卡長度、CPU 塔散/水冷排尺寸（240/280/360mm）、CPU 散熱器高度，都要對照機殼規格表的「最大支援長度/高度」，尤其小機殼（ITX/M-ATX）特別容易卡到。
- 散熱器扣具要支援自己的 CPU 腳位（不同世代 AM4/AM5、LGA1700/1851 扣具不一定通用，選購前查廠商相容清單）。
- 機殼前面板網孔（mesh）進風量通常優於強化玻璃，若重視散熱/靜音平衡要注意這點取捨。

**顯卡 PCIe 插槽「位置」（第幾槽）也要檢查，不只是插槽數量/版本**：主機板規格表通常只寫 PCIe 插槽數量和版本（Gen4/Gen5），但顯卡實際插在「第一槽」還是「第二槽」（甚至更下面）在小型機殼（M-ATX/ITX 這類）裡會直接影響裝得下裝不下。優先推薦顯卡插槽在第一槽（離 CPU 最近）的主機板；如果是插在第二槽，顯卡在機殼裡的實際安裝高度會偏低，容易跟機殼底部風扇或線材空間打架，可能被迫只能裝比較薄的顯卡，或底部風扇要換成超薄型（例如 Scythe Kaze Flex 這類薄框風扇）才塞得下，一般厚度的風扇裝不下。
  這種「主機板+機殼實際搭配裝機」的淨空問題，官方規格表幾乎不會寫，單靠查規格查不出來，**要提醒使用者自己去找同款主機板搭配該機殼的實際裝機心得/開箱文/論壇文章**，不要只憑規格表就斷定裝得下。

**空冷 vs 水冷（AIO）的推薦立場**：對一般被推薦的對象，預設推薦空冷，優先度高於水冷。常見誤解是「水冷比較安靜」——實際上水冷一樣要靠風扇把排熱吹出去，並不會比較安靜，某些情況下（水泵噪音 + 排風扇）反而更吵。認清這點之後，水冷真正的優點其實只剩：
  - 外觀（機殼內視覺效果、走線美觀）
  - 極少數非常頂規、高發熱量的 CPU，空冷壓不住才需要水冷來壓制熱量
  水冷本身還多一個幫浦/水路的故障風險與長期保養問題，不是「無腦選貴的水冷比較好」。回答時要主動點出這個常見誤解，不要預設使用者想要水冷就直接順著推薦。

### M.2 / 儲存
- 檢查 M.2 插槽的 PCIe 世代（Gen3/4/5）是否符合 SSD 規格，插錯代數不會壞但跑不到應有速度。
- 部分主機板 M.2 插槽會跟 SATA 或另一個 PCIe 插槽共享頻寬，插滿全部插槽時要查說明書確認會不會互相閹割。

### CPU/GPU 效能等級是否失衡（頭重腳輕 / 腳重頭輕）
這不是相容性問題（裝得下、開得了機），是效能搭配問題，但每次看到規格單都要順手檢查：CPU 等級跟 GPU 等級落差大不大，避免其中一方大幅拖累另一方的效能發揮（例如中高階 CPU 配入門 GPU，遊戲情境下 GPU 先變瓶頸，CPU 的效能用不到）。

發現落差時的處理方式：
- **明確指出來**，讓使用者知道這個組合在效能配置上偏頭重腳輕（或反過來），不要因為其他項目都合格就跳過這塊沒提。
- **但不要假設是使用者組錯**。等級落差很常是刻意的取捨，常見的合理原因包括：當下缺貨只買得到特定型號、外觀/系列要跟機殼或其他零件對到（例如同系列外觀好看，或機殼設計偏向搭配特定廠牌卡）、預算分兩階段規劃（先組主機之後再單獨升顯卡）。
- 遇到這種情況，先指出落差是什麼、大概會有什麼實際影響（例如「這個 GPU 等級在多數遊戲情境下會比 CPU 先觸頂，CPU 效能沒被完全榨乾」），再問使用者是不是刻意的選擇；如果使用者說明是刻意取捨，就不用重複說教，肯定這是他知情下的決定即可。

## 預算分配

> ⚠️ 傳統上會有「GPU 佔 35–45%、CPU 佔 15–20%…」這類固定比例的經驗法則，但**這套比例現在已經不可靠**：記憶體、SSD、顯卡近期漲價幅度都很大（例如 DDR5 32GB 一度逼近 1.5 萬台幣），導致這幾項在總預算裡的占比被硬生生推高，不再是舊比例能反映的狀態。不要直接套用舊的固定比例表回答使用者。

正確做法：
1. 先查目前記憶體、SSD、顯卡的實際行情（這三項是這波漲價的重災區）：DIY 零件用上面的 `scripts/coolpc_price.py`，其餘用 web search。
2. 抓出目前的總預算需求後，再跟使用者討論怎麼分配——**同樣的規格需求，現在需要抓的總預算通常比舊經驗法則以為的要高不少**，要提醒使用者這件事，不要讓他用過時的心理預期去抓預算。
3. 不要為了硬湊某個百分比而犧牲 PSU 品質或機殼相容性（這塊經驗法則仍然成立：CPU/GPU 花大錢但配雜牌 PSU 或過小機殼，是論壇上最常被吐槽的組裝失誤）。

## 已知地雷類型（通用模式，非特定型號）

型號會一直改朝換代，這裡列的是**模式**而不是寫死的型號黑名單，之後使用者可以補充目前市面上具體踩到的型號：

- 主機板 VRM（供電模組）用料不足的入門板，硬扛高階/高功耗 CPU 容易過熱降頻。
- 顯卡「公版」與「非公版」散熱設計差異大，同型號不同廠牌實際溫度/噪音可能差很多，購買前看實測評測而非只看規格表。
- 筆電/品牌機常見「規格看起來一樣但關鍵零件（如 SSD 控制器、面板色域）縮水」的隱藏閹割版，選購時要對照詳細規格而非只看型號。
- 二手顯卡要留意是否為礦卡（長時間高負載運轉），可從風扇軸承聲音、保固紀錄、賣家說法判斷，但無法百分之百確認。

**時效性地雷（現況，之後可能過時，回答前用 web search 確認是否仍然成立）**：美光（Micron）已退出消費級記憶體市場。這代表：
  - 未來要出保（保固維修/更換）可能會變得麻煩，因為原廠消費級通路已經收掉。
  - 就算廠商/經銷商同意退原購買價，因為記憶體之後可能持續漲價，退回的錢也買不回同規格的全新品——等於實質上是虧的。
  買美光消費級記憶體（或其子品牌）前要提醒使用者這個風險；如果使用者在意長期保固與置換成本，優先建議還留在消費級市場、保固管道健全的品牌。

## 購買時機判斷

- 新一代 GPU/CPU 上市前後，舊代產品常會降價，若不急著用，觀察新品發表時間點再決定是否等待。
- 大型促銷檔期（如雙11、黑五、電商年中慶）常是甜蜜點，但也要對照長期價格曲線判斷是否真的划算，避免被「假降價」（先漲後降）誤導。
- 缺貨/漲價潮（例如記憶體或顯卡因市場因素大漲）時，若非急用可考慮延後採購或改買替代規格。

## 重要提醒

價格、上市時間、目前市面熱門型號這類資訊變動非常快，**不要用這份 skill 裡的資訊臆測目前的實際價格或型號是否還在賣**。回答使用者時，具體型號/價格請提醒使用者自行到當下的論壇（PTT 電蝦版等）或比價網站核對最新狀況，這份 skill 提供的是不太會過時的檢查邏輯與經驗法則。
